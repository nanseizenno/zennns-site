本页用于说明 TPCA / PCN 相关技术交流、PoC 和初步合作方式。

合作不需要从完整系统开发开始。

更适合的方式是：

> **先选择一个明确的目标状态入口，明确问题范围、PCN 位置、相关状态和 PoC 输出，再判断是否进入后续阶段。**

---

## 1. 主要合作方向

### 自动化执行单元前置判定

适合自动化系统集成商、机器人工作站厂商、PLC / HMI 相关企业，以及制造企业生产技术部门。

典型问题包括：

- 设备已经 Ready，但仍不能进入下一阶段；
- PLC 中存在大量 Ready、Interlock 和 Handshake，现场仍需要查程序定位原因；
- 机器人、视觉、安全和下游状态相互关联，异常处理较多依赖工程师经验。

初步合作可从以下内容开始：

- 当前状态与目标状态；
- 目标状态入口及 PCN 候选位置；
- 代表性多源状态；
- C / A / E 状态映射；
- S / D / B 判定范围；
- 代表性控制路径；
- HMI / Web 显示范围。

相关案例：

[自动化执行单元前置判定案例](/zh/cases/automation-execution-unit-pre-control/)

---

### MES / WCS 协同停滞诊断

适合 MES / WCS 企业、AGV / AMR 系统商、制造业 DX 方案商，以及存在多设备协同停滞问题的制造企业。

典型问题包括：

- 任务存在，但群体有效执行能力持续下降；
- 系统显示 Waiting、Pending 或 Blocked，但不能直接说明协同停滞原因；
- 单体设备没有明显故障，但系统整体吞吐持续下降；
- 停滞原因仍需要人工跨多个系统核对日志和状态。

初步合作可从以下内容开始：

- 最小可观测状态；
- 群体停滞事件识别；
- 代表性群体状态或指标；
- 基础停滞结构分析；
- MES / WCS 页面显示；
- 事件报告和增强记录范围。

相关案例：

[MES / WCS 协同停滞诊断模块案例](/zh/cases/collaborative-stagnation-diagnosis/)

---

### 生产 DX 状态迁移条件设计

适合制造企业 DX、生产技术、质量、设备、保全部门，以及 MES / QMS / 制造数据平台相关企业。

典型问题包括：

- MES、质量、设备和人员系统均有数据，但下一阶段是否可以进入仍依赖人工确认；
- 质量放行、保全解除、工单切换等状态迁移条件缺少统一表达；
- Waiting、Hold、Manual Confirm 等状态反复出现，但缺少可复盘的状态迁移判定履历。

初步合作可从以下内容开始：

- 当前状态与目标状态；
- 跨系统目标状态入口及 PCN 位置；
- C / A / E 状态映射；
- S / D / B 判定范围；
- 代表性多路径控制；
- PCN Trace 及后续履历分析范围。

相关案例：

[生产 DX 状态迁移条件设计与履历分析案例](/zh/cases/production-dx-state-transition/)

### 其他应用讨论

对于其他具有明确目标状态入口的工程系统，也可以讨论 TPCA / PCN 的适用性。

是否适合建立 PCN，不取决于设备或行业名称，而取决于：

- 当前状态和目标状态是否明确；
- 相关状态是否可观测；
- 是否需要多个状态共同参与前置判定；
- 判定结果是否会影响实际控制路径；
- 是否具有形成判定履历的工程价值。

相关说明：

[TPCA / PCN 适用场景分析](/zh/notes/tpca-pcn-applicable-scenarios/)

## 2. 初次沟通

首次联系时，不需要提供完整程序、数据库、接口资料或企业机密。

建议简要说明：

- 所属行业或系统对象；
- 当前希望解决的问题；
- 当前状态和目标状态（如已能够明确）；
- 涉及的主要设备、系统或角色；
- 希望讨论技术交流、PoC、产品合作或其他合作方式。

首轮沟通主要判断：

> **该问题是否适合使用 TPCA / PCN，以及是否具有进一步开展 PoC 的价值。**

如果现有系统已经能够有效解决相关问题，也没有必要为了使用 TPCA / PCN 而额外增加工程结构。

## 3. 合作与公开边界

本站公开内容主要用于说明工程问题、总体架构、核心概念、公开案例和应用方向。

以下内容不属于本站一般公开范围：

- PCN Runtime 的具体实现；
- 配置结构和 Rule Pack；
- 完整控制仲裁规则与控制优先关系；
- 关键工程参数；
- PCN Trace 详细数据结构；
- 接口与部署方式；
- 其他非公开实施方案。

如合作需要涉及上述内容，可根据项目阶段和资料范围确认保密要求，并在必要时签署保密协议（NDA）。

涉及专利授权、知识产权归属、许可方式等事项，应通过正式协议确认；必要时由专利代理人或律师提供专业意见。
