## 为什么是 CAE-SDB？

在 TPCA / PCN 中，CAE-SDB 用于一次明确目标状态入口之前的结构化判定。

当前定义为：

- C = Condition，条件；
- A = Authority，许可；
- E = Execution Chain，执行链；
- S = Structure，结构完整性；
- D = Dynamics，动态时序有效性；
- B = Boundary，边界。

CAE-SDB 由两个分析轴构成：

```text
CAE——状态迁移功能角色轴

SDB——状态验证轴
```

CAE 用于确定相关状态在本次目标状态入口中承担的迁移功能角色。

SDB 用于判断这些状态的结构完整性、动态时序有效性以及相对于预定义边界的位置关系。

---

## 1. CAE：目标状态入口的迁移功能角色轴

目标状态明确后，一次状态迁移需要分别判断：

```text
C：具不具备？
A：允不允许？
E：接不接得住？
```

其工程功能位置可表示为：

```text
进入前                 目标状态入口                 进入后
  │                         │                         │
  C                         A                         E
条件                       许可                     执行链
```

“进入前—入口—进入后”表示 C / A / E 所对应的工程功能位置，不表示 E 在进入目标状态以后才进行判定。

C、A、E 均在目标状态入口之前进入 PCN 的前置判定。

### 1.1 C：条件

C 用于判断进入目标状态前所需的现场条件、对象条件、识别条件、数据条件、任务条件、参数条件等是否成立。

代表性判断包括：

```text
工件是否存在？
识别结果是否成立？
位置是否正确？
必要参数是否具备？
任务数据是否完整？
```

C 判断进入目标状态所需的事实条件是否已经具备。

### 1.2 A：许可

A 用于判断系统是否允许进入目标状态。

代表性判断包括：

```text
安全许可是否成立？
上位系统是否授权？
区域是否允许进入？
资源锁是否取得？
是否需要人工确认？
对方设备是否已经许可？
```

关键 A 可以构成独立必要约束。

当：

```text
C = 成立
E = 成立
A = 不成立
```

且该 A 属于关键许可时，不得进入目标状态。

### 1.3 E：执行链

E 用于判断进入目标状态后，后续执行链是否能够继续接续。

E 不等于单一设备的 Ready。Ready 可以作为 E 的一个输入，但不能覆盖 E 的全部含义。

E 可以涉及：

```text
本体设备
末端执行机构
下游承接
备用路径
回退路径
异常排出路径
结果上传或回写链路
```

因此，CAE 分别回答：

```text
C：具不具备？
A：允不允许？
E：接不接得住？
```

CAE 不按照机器人、PLC、MES 等信号来源进行分类，而是根据相关状态在本次目标状态入口中承担的迁移功能角色进行映射。

## 2. SDB：状态验证轴

确定相关状态属于 C、A 或 E 后，还需要判断：

- 相关状态所依赖的工程结构是否已经建立；
- 当前取得的状态是否仍然有效；
- 当前状态相对于预定义边界处于什么位置。

SDB 分别回答：

```text
S：结构建立了吗？
D：当前状态有效吗？
B：当前状态在界内吗？
```

### 2.1 S：结构完整性

S 用于判断相关对象、信号、接口、映射关系、许可来源、角色及执行链边界是否已经定义、接入并可观测。

代表性判断包括：

```text
需要的信号定义了吗？
接口接入了吗？
映射关系明确吗？
许可来源明确吗？
角色关系明确吗？
执行链边界定义了吗？
这些状态可以被观测吗？
```

当上述基础结构不存在或不完整时，后续状态判定缺少相应的工程基础。

S 判断完成本次目标状态入口所需的工程结构是否建立完整。

### 2.2 D：动态时序有效性

D 用于判断当前取得的状态是否仍具有本次目标状态入口的判定效力。

例如：

```text
机器人就绪状态 = TRUE
```

该变量存在，不等于其当前状态仍然有效。还需要判断：

```text
是否超时？
是否刷新？
是否抖动？
是否发生冲突？
是否存在延迟？
多个状态源是否同步？
置信度是否仍然有效？
许可是否刚刚被撤销？
```

因此：

```text
状态存在 ≠ 状态当前有效
```

D 判断相关状态在时间和状态变化过程中是否仍然有效，包括超时、未刷新、抖动、冲突、延迟、不同步、低置信度、许可撤销等动态时序问题。

### 2.3 B：边界

B 用于判断当前有效状态相对于预定义边界的位置关系。

例如，某尺寸允许范围为：

```text
19.90 mm ～ 20.10 mm
```

当前测量结果为：

```text
20.06 mm
```

B 判断：

```text
20.06 mm 是否处于规定边界内？
```

相同逻辑可用于：

```text
温度范围
压力范围
缓存容量
负载率
距离
速度
允许区域
许可等级
状态集合
其他预定义工程边界
```

B 不等于等待、回流、人工确认或安全锁定。这些属于后续控制路径。

B 只判断当前有效状态相对于预定义边界的位置关系。

## 3. CAE 与 SDB 的双轴关系

CAE 与 SDB 分别处理不同问题。

CAE 判断：

> **相关状态在本次状态迁移中承担什么功能角色。**

SDB 判断：

> **相关状态的结构完整性、动态时序有效性以及相对于预定义边界的位置关系。**

可表示为：

```text
CAE——状态迁移功能角色轴

C：具不具备？
A：允不允许？
E：接不接得住？
```

```text
SDB——状态验证轴

S：结构建立了吗？
D：当前状态有效吗？
B：当前状态在界内吗？
```

完整关系如下：

```text
目标状态入口
     │
     ▼
识别与本次迁移有关的状态
     │
     ▼
CAE：迁移功能角色映射
     │
     ├── C：具不具备？
     ├── A：允不允许？
     └── E：接不接得住？
               │
               ▼
SDB：对相关状态进行性质判定
               │
     ├── S：结构建立了吗？
     ├── D：当前状态有效吗？
     └── B：当前状态在界内吗？
               │
               ▼
        CAE-SDB 判定结果
```

CAE 与 SDB 不是两套重复的状态分类。CAE 是状态迁移功能角色轴，SDB 是状态验证轴。

## 4. 工程示例：工件尺寸判定

假设某自动化设备在进入加工阶段之前，需要确认工件尺寸。

工件尺寸属于 C 状态变量：

```text
C 状态变量：
工件尺寸
```

其工程含义为：工件尺寸是进入加工阶段前需要确认的条件状态。

对该状态变量可进一步进行 S / D / B 判定。

### 4.1 C-S：结构完整性

```text
测量对象是否明确？
尺寸检测传感器是否接入？
信号地址是否正确？
单位是否统一？
测量值是否与当前工件建立正确对应？
```

### 4.2 C-D：动态时序有效性

```text
这个尺寸是不是当前工件的测量值？
测量结果是否已经刷新？
数据是否超时？
工件移动以后旧值是否已经失效？
```

### 4.3 C-B：边界

假设规定：

```text
允许尺寸：
19.90 mm ～ 20.10 mm
```

则 B 判断当前有效测量值是否处于该范围内。

例如：

```text
20.06 mm → 在界内
20.18 mm → 超出边界
```

在该示例中，C 表示“工件尺寸”在本次目标状态入口中承担条件状态的迁移功能角色。

S / D / B 分别判断：

```text
该尺寸状态所需的工程结构是否建立完整；
当前取得的尺寸值是否仍然有效；
当前有效尺寸值是否处于规定边界内。
```

## 5. A 与 E 的 SDB 判定示例

相同的判定方式适用于 A 与 E。

### 5.1 A：许可

某项安全许可属于进入目标状态所需的 A 状态。

```text
A-S：
许可来源、接口和授权关系是否建立完整？

A-D：
许可当前是否仍然有效？

A-B：
当前许可状态或授权等级是否处于允许进入的规定边界内？
```

### 5.2 E：执行链

下游承接能力属于进入目标状态后执行链能否继续接续的 E 状态。

```text
E-S：
下游承接链及相关接口是否定义完整？

E-D：
当前下游能力状态是否仍然有效？

E-B：
当前容量、负载或位置等状态是否处于允许承接的规定边界内？
```

## 6. CAE-SDB 判定结果、控制仲裁与多路径控制

CAE-SDB 的输出为 CAE-SDB 判定结果。

处理关系为：

```text
CAE-SDB 判定结果
        ↓
     控制仲裁
        ↓
     多路径控制
```

控制仲裁根据关键许可、控制约束以及多个判定结果处理控制优先关系。

多路径控制根据控制仲裁结果形成实际工程控制路径。

代表性路径包括：

```text
允许进入
等待
重新检查
重试
回流
降级
人工确认
禁止进入
安全锁定
其他预先定义路径
```

S / D / B 不是控制动作。

其中，B 只表示边界判定，不代表等待、回流、人工确认、安全锁定等具体控制路径。

CAE-SDB 提供进入控制仲裁之前的结构化判定基础。

## 7. 当前理论边界与后续验证

本文说明 CAE-SDB 当前的双轴结构解释。

本文不主张已经通过数学方法证明：

```text
在所有可能工程系统中，
CAE 与 SDB 已经不存在任何可扩展空间。
```

当前验证对象限定为一次已经明确的目标状态入口。

### 7.1 CAE 第四变量反例测试

CAE 的验证对象是：

> **是否存在 C / A / E 之外，但又是一次明确目标状态入口不可缺少的第四种迁移功能角色 X。**

要求：

```text
X ≠ C
X ≠ A
X ≠ E
```

同时，X 不能通过改变 C / A / E 的现有定义强行归入其中。

### 7.2 SDB 第四性质反例测试

SDB 的验证对象是：

> **对于已经纳入本次迁移判定的相关状态，是否存在 S / D / B 之外，但又不可缺少的第四种独立判定性质 P。**

要求：

```text
P ≠ S
P ≠ D
P ≠ B
```

验证目标是寻找当前 CAE-SDB 无法解释的现实对象，而不是预设 CAE-SDB 已经完备。

如果后续跨行业、跨设备和跨系统案例反复出现无法由当前定义自然表达的独立迁移功能角色或判定性质，应将其作为新的理论问题处理。

## 8. 结构概括

CAE-SDB 由状态迁移功能角色轴和状态验证轴构成。

### CAE——状态迁移功能角色轴

```text
C：具不具备？
A：允不允许？
E：接不接得住？
```

CAE 对应围绕目标状态入口的三个工程功能位置：

```text
进入前 → 目标状态入口 → 进入后
```

C、A、E 均在目标状态入口之前进入 PCN 的前置判定。

### SDB——状态验证轴

```text
S：结构建立了吗？
D：当前状态有效吗？
B：当前状态在界内吗？
```

完整处理关系为：

```text
目标状态入口
     ↓
识别相关状态
     ↓
CAE：状态迁移功能角色映射
     ↓
SDB：状态验证
     ↓
CAE-SDB 判定结果
     ↓
控制仲裁
     ↓
多路径控制
```

CAE-SDB 用于一次明确的目标状态入口前，识别相关状态在迁移中的功能角色，并分别判断这些状态的结构完整性、动态时序有效性以及相对于预定义边界的位置关系。

CAE-SDB 判定结果继续进入控制仲裁与多路径控制，用于形成后续工程控制路径。
