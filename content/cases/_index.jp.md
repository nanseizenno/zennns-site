本ページでは、TPCA / PCN を異なるエンジニアリング対象へ適用した公開事例を整理する。

自動化実行ユニット、製造現場の協調システム、製造DXにおけるシステム横断の状態遷移を代表例として、明確な目標状態入口（Target State Entry）を基準に、関連状態の取得、C / A / E 状態マッピング、S / D / B 判定、制御優先度調停（Arbitration）、複数経路制御（Multipath Control）、実行結果、PCN Trace までをどのように構成するかを示す。

## 事例一覧

### [自動化実行ユニット前判定事例](/jp/cases/automation-execution-unit-pre-control/)

画像認識を用いた搬送ラインのロボットユニットを代表例として、「ピックアップ段階への進入」という目標状態入口を対象に、画像認識、ロボット、安全装置、搬送コンベヤ、下流受入、上位システムなどの状態を C / A / E へ整理し、S / D / B 判定を行う。

その判定結果を制御優先度調停、複数経路制御、目標状態入口に対する制御結果、選択された制御経路の実行、実行結果、PCN Trace へつなげ、一回の状態遷移前制御を工程順に説明する。

### [MES / WCS 協調停滞診断モジュール事例](/jp/cases/collaborative-stagnation-diagnosis/)

製造現場の協調停滞を対象に、MES、WCS、搬送主体、ステーション、経路資源、許可、下流受入などに分散した状態を、「継続可能な協調実行状態への進入」という目標状態入口に対応付けて整理する。

C / A / E 状態マッピングと S / D / B 判定に加え、群集約指標、協調停滞識別、停滞構造分類を用いて群全体の協調状態を分析し、その結果を制御優先度調停、複数経路制御、目標状態入口に対する制御結果、実行結果、PCN Trace へ展開する。

### [製造DX 状態遷移条件設計・履歴分析事例](/jp/cases/production-dx-state-transition/)

部品自動加工工程から作業員によるセル組立工程への移行を代表例として、MES、加工設備、品質システム、部品供給、作業者資格、セル設備、治具・工具、後続工程などに分散した状態を、「セル組立作業開始」という一つの目標状態入口に対応付けて整理する。

加工完了、品質結果、品質承認、作業者資格、セル設備 Ready などを C / A / E へ整理し、S / D / B 判定、制御優先度調停、複数経路制御、実行結果、PCN Trace を通じて、工程間の状態遷移条件を明示し、履歴として確認・比較できる形にする方法を説明する。

## 9工程のエンジニアリング分析順序

以下の9工程は、[TPCA / PCN 状態遷移前制御アーキテクチャ｜ホワイトペーパー](/jp/whitepaper/)で整理している基本的な工程順序であり、各公開事例を展開する際の共通骨格として使用する。

| 工程 | 概要 |
|---|---|
| **1. 現在状態（Current State）** | 今回の状態遷移が、どの状態・段階・経路位置から始まるかを明確にする。 |
| **2. 目標状態 / 目標状態入口（Target State / Target State Entry）** | 進入しようとする目標状態と、その前に判定すべき目標状態入口を明確にする。 |
| **3. PCN：関連状態取得 + C / A / E 状態マッピング** | 今回の状態遷移に直接関係する複数ソースの状態を取得し、Condition（条件状態）、Authority（許可状態）、Execution Chain（実行チェーン状態）へ整理する。 |
| **4. S / D / B 判定** | Structure（構造完全性）、Dynamics（動的時系列有効性）、Boundary（制御境界）の観点から判定し、CAE-SDB 判定結果と時間情報 T を形成する。 |
| **5. 制御優先度調停（Arbitration）** | 複数の判定結果、重要な許可、制御制約などの優先関係を処理する。 |
| **6. 複数経路制御（Multipath Control）** | 制御優先度調停の結果に基づき、進入許可、待機、再確認、代替経路、進入禁止などの制御経路を形成する。 |
| **7. 目標状態入口に対する制御結果** | 今回の目標状態入口に対して、進入するか、保留するか、禁止するか、別の制御方向へ進むかを明確にする。 |
| **8. 選択された制御経路の実行と実行結果** | 対応する実行主体が選択された制御経路を実行し、実際に形成された結果を確認する。 |
| **9. PCN Trace** | 今回使用した状態、判定結果、制御結果、実行結果、時間情報 T を一つの状態遷移判定履歴として関連付ける。 |

各事例では、この9工程を共通骨格として用いながら、対象に必要な分析を工程内へ追加する。

例えば、MES / WCS 協調停滞診断では、第4工程に群集約指標、協調停滞識別、停滞構造分類を加える。製造DX事例では、自動加工工程からセル組立工程への移行に必要な品質、作業者資格、部品供給、セル設備などの状態を具体的に扱う。

---

三つの事例は同じ工程骨格を共有するが、各事例では対象となるエンジニアリング問題に応じて、必要な状態、判定、分析、制御経路を具体化している。

本ページは、TPCA / PCN 状態遷移前制御体系における公開応用事例の索引である。
