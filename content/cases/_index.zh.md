这里整理 TPCA / CAE-SDB 在不同工程对象中的公开说明案例。

这些案例分别从自动化执行单元、制造现场协同系统和生产 DX 跨系统状态迁移三个层面，说明 PCN 如何围绕明确的目标状态入口，对多源状态进行结构化判定，并形成多路径控制与状态记录。

## 案例列表

### [自动化执行单元前置判定案例](/zh/cases/automation-execution-unit-pre-control/)

> 以视觉识别输送线机器人单元为代表例，说明 PLC / PCN 如何在机器人进入抓取阶段之前，对视觉、机器人、安全、输送带、下游承接和上位系统信号进行 C / A / E 映射与 S / D / B 判定，并输出正常抓取、回流、异常分流、等待、禁止进入或安全锁定等控制路径。


### [MES / WCS 协同停滞诊断模块案例](/zh/cases/collaborative-stagnation-diagnosis/)

> 以制造现场协同停滞诊断模块为对象，说明为什么任务存在、设备在线、系统有状态记录，现场仍然会出现协同停滞，以及 MES / WCS 如何通过 PCN 对多源状态进行结构化判定、停滞识别、结构分型和多路径控制输出。


### [（核心案例）生产 DX 状态迁移条件设计与履历分析案例](/zh/cases/production-dx-state-transition-design/)

> 以“前工序完成 / 等待放行 → 下一生产阶段执行”为代表状态迁移入口，说明生产 DX 如何将分散在 MES、质量、设备、人员、保全、下游和追溯系统中的状态整理为 C / A / E 状态变量，并通过 S / D / B 判定、控制优先级仲裁、多路径控制和 PCN Trace，把原本依赖跨系统确认与工程师经验的状态迁移条件显式化、可记录化和可复盘化。
